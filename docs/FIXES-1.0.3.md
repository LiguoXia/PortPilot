# PortPilot 1.0.3：Windows 图标兼容性

## 修复

此前侧栏、窗口按钮、搜索下拉、刷新等图标使用 `Segoe Fluent Icons` 字体的私用区字符；目标系统无法解析对应字形时会显示方框。现已全部改为应用内置的 WPF 矢量几何图形，不读取或安装图标字体，不新增运行时依赖。

`Views/Icon.cs` 统一管理图形与绘制，继承文字前景色并支持尺寸缩放。下拉箭头显式使用主题文字颜色，避免深色主题下落入系统按钮的黑色默认前景。装饰图标不接收鼠标事件，按钮保留原有命令、快捷键与提示；仅含图标的按钮补充可访问名称。空状态和进程树同样改用矢量图标。

## 验证

2026-09-20，Windows 11 x64，.NET SDK 8.0.425。

- Release 构建：0 警告、0 错误；72 项 xUnit 测试全部通过。
- 发布 EXE 在独立便携目录执行 WPF UI 冒烟测试，所有页面及详情正常渲染。
- 对实际主窗口图标指定不存在的字体，比较前后绘制像素：结果一致且非空。无需修改或卸载系统字体。
- 检查导航选中/未选中颜色继承、深浅主题下拉箭头对比度。
- 15 种矢量图标、9/16/32 DIP 尺寸，在 100% / 125% / 150% / 175% / 200% 离屏渲染中均非空，并检查图标图集和主窗口截图。
- 搜索输入与提交、搜索框文本裁切、Network 多端点切换和刷新回归通过。

缩放检查为离屏渲染，不等同于实际跨显示器 DPI 切换测试。用户截图仅用于定位问题，没有上传至仓库；公开截图来自独立测试副本。
