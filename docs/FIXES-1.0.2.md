# PortPilot 1.0.2 修复与验证

验证日期：2026-09-20，Windows 11 x64，.NET SDK 8.0.425。

## 输入卡顿

原先文本输入停止 250 毫秒后会刷新三个 CollectionView，慢速输入时反复触发列表筛选和页面布局。

现在输入文字、粘贴、选择字段和修改精确选项只编辑待提交条件；按 Enter 或点击“搜索”才应用条件并打开分组结果。自动刷新、F5 和筛选按钮使用上次提交的条件。清空后提交可显示全部结果。常用端口、收藏和 PID 端口快捷查询仍立即应用。

UI 回归使用发布 EXE 的实际搜索控件：

- 先提交真实监听端口，再逐字输入中文进程名，每字间隔 300 毫秒，超过原先的防抖时限。
- 同时切换字段和精确选项，断言三个列表视图没有 Reset、页面没有跳转，结果仍匹配已提交端口。
- 手动扫描和切换 TCP 筛选不会应用未提交条件。
- 通过路由 Enter 事件和按钮 UI Automation 分别提交，验证 PID、端口、进程名的包含/精确匹配及大小写行为。
- 清空并提交恢复全部结果。

## Network 连续异常弹框

Network 页的 `Run.Text` 使用默认绑定模式，尝试回写 `InspectorRow.Protocol`、`State` 只读属性。两处均显式改为 `Mode=OneWay`。

UI 回归创建 12 个真实 TCP 监听端点、一个 UDP 端点和一对已建立 TCP 连接，在 Overview / Network / More 之间切换三轮，并在 Network 展示期间刷新与关闭端点。逐行检查实际渲染的协议和状态，确认已关闭监听端点移除。测试中的未处理 UI 异常会使进程以非零状态退出，不跳过此类异常。

## 结果

- Release 构建：0 警告、0 错误。
- xUnit：72 通过、0 失败、0 跳过。
- 发布版 WPF UI 冒烟与上述两项回归：通过。
- 浅色/深色、1200/900 宽度，中文、含下伸部字母、长路径：无垂直裁切，文本行高 16.5 DIP、视口高 17 DIP。
- 100% / 125% / 150% / 175% / 200% 离屏渲染检查通过；不是物理显示器间 DPI 切换测试。

测试在独立便携目录运行。完整截图和原始日志仅在本地保留，公开截图只包含测试窗口或无用户数据的界面。搜索测试验证输入不再触发查询，不声称消除扫描及其他操作的全部 UI 开销。
