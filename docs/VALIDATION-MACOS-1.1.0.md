Mac runner 使用 macOS 15；macOS 12 最低版本写入应用清单，但没有在 macOS 12 真机执行验证。

## 已验证

- 在每种芯片的原生 runner 上创建 IPv4 / IPv6 TCP 监听、UDP 绑定和已建立连接，确认地址、协议、端口、远程端口与当前 PID。
- 读取自身进程启动时间、内存、路径、命令与详情。
- 对测试创建的 `/bin/sleep` 子进程发送 SIGTERM / SIGKILL，等待实际退出；伪造启动时间的目标被拒绝，子进程仍存活。进程退出后重复操作被拒绝。
- 保护系统关键进程、root 与未知身份；进程树去重、子进程优先、排除时间不符的父子关系。
- 搜索规则、JSON 保存与损坏恢复、收藏 / 备注 / 历史、CSV 公式注入防护等既有业务测试在 Mac 原生运行。
- 包内应用实际启动；访问六个页面，切换浅色 / 深色主题，执行 PID 过滤及详情读取。
- ZIP 解压后验证整个 `.app` 的 ad-hoc 签名，使用 `lipo` 核对目标架构，再次启动应用。
- DMG 只读挂载，校验应用签名与 Applications 链接，通过 `open -W -n` 启动 `.app`，等待应用完成冒烟测试并写出 PASS，然后卸载。
- 本地使用 `--ui-preview <目录>` 在隔离数据目录生成合成数据的 12 张页面 / 主题截图；检查列表、搜索栏、按钮及布局。另检查 ARM64 Mac 实际渲染截图。
- NuGet 已知漏洞扫描未报告 Mac 项目及其传递依赖存在已知漏洞（以检查时数据源为准）。

## 验证边界

没有 Apple Developer ID 证书 / 公证凭据，发行包使用 ad-hoc 签名。CI 未模拟浏览器下载带来的隔离属性及用户 Gatekeeper 提示，也未验证组织管理的 Mac 策略。

未测试 macOS 12/13/14 真机、长期内存压测、数千端点下的交互延迟、多显示器和全部辅助功能；不能将 Windows 1.0.4 的性能数字作为 Mac 性能结果。目标进程架构与签名、环境变量不在本版功能内。更多平台语义见 [macOS 使用说明](MACOS.md)。
