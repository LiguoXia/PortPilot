# 1.0.1 搜索优化验证

## 修改

1. 自定义 TextBox 模板不再把 Padding 额外应用为内容宿主的 Margin，消除重复内边距造成的内容裁切。
2. 标题栏搜索控件独立分配字段选择、文本输入和精确开关的空间；输入框单行、垂直居中，长文本支持随光标滚动。
3. 新增本地端口、远程端口、PID、进程名称、程序路径和 IP 地址字段筛选，保留综合搜索；文本支持包含或完整匹配。
4. 搜索逻辑、收藏分组、端口快捷查询、PID 反查和命令面板统一使用相同字段语义。进程树在筛选变化时同步更新。

## 自动化结果

- Release 编译：0 警告、0 错误。
- xUnit：72 项通过，包括原有 28 项和新增 44 项搜索用例。
- 搜索用例覆盖：PID/本地端口/远程端口同号不串项、精确与包含、大小写、中文路径、字段前缀、空值、非法端口、IPv6 等价写法及收藏类型。
- 发布版 WPF 冒烟：通过真实控件绑定切换字段/精确开关，用当前进程及真实临时 TCP 端点验证结果。
- 实际 TextBox 字符行高约 16.5 DIP，内容视口 17 DIP，中文与 `gypj`、长路径均位于视口内，没有垂直裁切。
- 覆盖浅色/深色、1200/900 宽窗口；搜索栏以 100% / 125% / 150% / 175% / 200% 渲染检查。离屏渲染不等同于物理显示器切换测试。

公开搜索栏截图位于 `docs/public/`。完整诊断截图、原始结果和测试报告由本地构建生成，不进入公开仓库；分别位于 `docs/screenshots/`、`docs/ui-smoke-results.txt` 和 `TestResults/tests.trx`。

本次不修改用户收藏、备注或配置的数据结构。发布包不包含测试用数据，原有 data 可以继续使用。
